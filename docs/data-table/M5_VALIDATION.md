# M5 验收与性能证据

日期：2026-10-29。M5 代码已完成；列虚拟化按证据暂缓，人工辅助技术/跨浏览器补验仍未完成。

## 测量方法

- Apple M3 Pro / macOS arm64，Chrome 156.0.8078.48，Desktop Chrome 1280×720，设备倍率 1，无 CPU/网络降速。
- Vite production 构建，独立夹具和预览端口 4175。每组重新导航 3 次，每次交替排序/选择 10 次（合计 30 个采样）。最终版本另测每次 10 次列显隐视图切换。
- 交互耗时从 DOM click 到连续两帧 requestAnimationFrame；它是渲染响应代理指标，不是物理屏幕呈现延迟。导航到首个行可见为启动耗时，包含自动化/页面加载成本。3 次启动取最大值，样本不足以推断稳定的启动 p95。
- 四组完全本地生成：100×20、10,000×20、100×100、5,000 节点树（100 根、每根 49 个子节点，全部展开）。无后端请求，因此不测 API 延迟、不代表真实数据库或网络吞吐。
- 原始基线基于 M4 `d545305`；先测轻量优化，再引入行虚拟化。轻量优化减少重复计算与滚动锚点测量，但未解决全量 DOM 的秒级成本。
- 最终采样与其他浏览器套件串行运行。原始结果见 [M5 性能采样 JSON](M5_MEASUREMENTS.json)；其中基线与中间阶段未测列视图切换，不能虚构对应提升比例。最终夹具多了两个测试按钮，DOM 总量允许这一固定差异。

## 性能对比

| 样本 | 基线交互 p95 | 轻量优化 p95 | 虚拟模式 p95 | DOM 基线 → 虚拟 | 虚拟挂载行 | 启动最大：基线 → 虚拟 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 100×20 | 46.3ms | 43.2ms | 32.4ms | 2,216 → 501 | 18 | 158 → 127ms |
| 10,000×20 | 4345.5ms | 4506.1ms | 32.5ms | 210,116 → 501 | 18 | 5129 → 77ms |
| 100×100 | 187.4ms | 187.1ms | 39.8ms | 10,456 → 2,181 | 18 | 332 → 108ms |
| 5,000 树节点×20 | 2388.1ms | 2419.2ms | 33.6ms | 105,116 → 501 | 18 | 2551 → 73ms |

普通 100×20 保持完整 100 行渲染，最终排序/选择 p95 为 **42.5ms**（基线 46.3ms），列视图切换 p95 为 **34.4ms**，3 次启动最大 149ms。没有默认给已有业务页开启虚拟化。

最终虚拟模式的每组列视图切换 p95 均小于 200ms。12 次挂载/卸载后进行强制 GC，排除前 4 次暖机后堆增长约 **0.50MiB**，低于 4MiB 趋势预算。该结果是有限轮次回归证据，不宣称长期运行绝无泄漏；当前客户端行模型仍需随输入 N 占用内存。

冻结本机回归预算：普通 100×20 和四组虚拟样本排序/选择、列视图交互 p95 <200ms；520px 视口每组挂载数据行 <80；循环卸载暖机后堆差 <4MiB。其他硬件、复杂业务单元格和真实网络需重新测量，不照搬本机数字。

## 已修复的专项问题

1. 同查询插入数据会让当前页末行移到下一页，修正测试对最后一行的预期。
2. 缓存每次删除 ID 就全量清理会破坏小幅插入的滚动锚点，改为有界历史 ID 集合和阈值清理。
3. 虚拟器晚于父视口绑定滚动元素，其初始偏移覆盖返回位置；显式绑定后延迟恢复，并在正文更新后记录锚点。
4. 动态高度直接跳至末尾时，新增测量高度可能把末行挤出视口；补偿底部尺寸变化，并将恢复改成一次性定位，避免持续的索引校正覆盖后续滚动。新增真实视口相交断言。
5. 固定列几何检查必须等待虚拟行重新挂载后取值，避免读取临时空节点；已改为条件轮询。
6. 夹具为普通列显式传入 `cell: undefined` 会覆盖默认单元格；已改为仅在自定义单元格时设置属性，并废弃该轮虚拟性能结果。本文 JSON 仅保留完整单元格的最终结果。

## 未覆盖与暂缓

- **DT-504 列虚拟化暂缓**：宽表基线 p95 187.4ms，行虚拟化已把它降至几十毫秒，不增加额外列裁剪复杂度。
- **DT-505 部分验收待补**：ARIA 行数/序号、焦点和分页替代已实现；未实际使用 VoiceOver/NVDA 连续朗读。Firefox、WebKit、原生 200% 缩放和真机触摸未覆盖，不以 Chromium 自动化替代。
- 行详情、行分组与虚拟化组合明确回退完整当前页；动态高度跨卸载的历史尺寸不持久化，按 ID 与估算再校正。列宽改变可能使远端行尚未测得的高度发生估算偏差。
- 这是可选组件能力；未把现有分页业务页改为一次加载 10,000 行。业务接入与完整交付矩阵属于后续 M6，未擅自开始。

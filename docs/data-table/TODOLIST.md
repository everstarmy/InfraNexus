# DataTable 强化任务清单

日期：2026-10-27。关联：[详细方案](ENHANCEMENT_PLAN.md) · [范围说明](README.md)。

## 执行规则

- 用户已授权 M0/M1；M0 已完成，M1 实现及自动化证据见 [M1 验收](M1_VALIDATION.md)，原生缩放/真机触摸补验保留未完成；M2 已实施并有 [验收记录](M2_VALIDATION.md)；M3 已实施并完成本轮自动化验证；M4 已实施用户列表和权限树试点；M5 代码已完成，人工兼容补验和列虚拟化暂缓项见 M5 验收；M6 代码已完成，跨浏览器/人工补验见 M6 验收。M0 证据见 [验收记录](M0_VALIDATION.md)，已有基础能力不重复标记为本轮新增。
- 每个任务完成后记录提交/文件、验证命令与结果；依赖缺失则保持未勾选并记录阻塞原因。
- `FE` 为前端，`BE` 为后端，`QA` 为验证，`DOC` 为文档。这里表示工作类别，不指定人员或要求多智能体并行。
- M0 → M1 → M2 → M3 为推荐主线；M4 按业务试点推进，M5 由性能证据驱动，M6 汇总纳入本次交付的能力。
- “可暂缓”不是默认交付要求。决定暂缓后注明原因和替代方案，阶段总结不得把它列为已实现。
- 每阶段完成以退出条件为准；没有真实后端测试时，不能仅凭 mock E2E 勾选后端语义任务。

## 暂不纳入主线的候选能力

以下能力不因列在此处自动进入当前实施任务：

| 候选 | 重新评估条件 |
|---|---|
| 云端视图同步/团队共享 | 明确跨设备或协作需求，设计所有权与字段权限 |
| XLSX 高级样式导出 | CSV 无法满足格式、多个工作表或类型保真需求 |
| 无限滚动 | 实际浏览模式不适合分页，并有游标/一致性策略 |
| 批量粘贴编辑/自动保存 | 单行编辑已稳定，业务要求明确，冲突/校验可解释 |
| 拖拽业务行排序 | 业务存在持久顺序字段，定义筛选/分页下的排序语义 |
| 公式/透视/协作表格 | 属于独立产品范围，不作为本表格强化隐含要求 |

## 范围与状态

用户已在本次对话中明确允许放开表格功能冻结限制，用于规划强大的数据表格。初始请求为编写方案与任务清单；用户随后授权实施 M0、M1、M2、M3、M4、M5 和 M6。M0 只增加测试基础设施与基线/契约文档，不新增生产功能或后端接口，不安装依赖。

本方案中的表格增强可进入后续实施范围，但不等于解除项目其他模块的功能冻结。跨页面共享视图、导出任务、批量接口等依赖按具体阶段设计，不能据此顺带建设通用报表平台、任务中心或审计平台。

M0 状态与证据见任务清单和验收记录；M1 功能已实现并完成自动化验证，原生缩放/真机触摸补验保持未完成；M2 已完成用户列表试点及相关代码，并通过 SQLite/PostgreSQL 查询验证；M3 已实现用户列表选择、批量状态、导出与复制，验证边界见 M3 记录；M4 已实现用户列表和权限树试点，见 M4 验收记录；M5 代码已完成，列虚拟化暂缓，人工兼容补验见 M5 验收；M6 已完成页面能力核对与接入代码，跨浏览器/人工补验见 M6 记录。历史文档的测试通过记录不能作为新增能力的验收证据。方案里的接口名称为设计草案，正式实施时以仓库实际依赖版本与类型检查结果为准。

## 阅读与维护约定

1. 先读方案的基线与分期，再按任务 ID 推进。
2. 阶段完成时同步任务清单、实际接口说明、测试证据与未覆盖环境。
3. 暂缓能力保持未完成并注明原因，不通过删掉任务或无证据勾选宣称完成。
4. 保留历史验收文件原位置，避免破坏现有 AGENTS.md 等文档链接。
